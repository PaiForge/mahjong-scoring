# Maestro フロー

操作と撮影のフロー。流し方・`testID` の引き方・Android の注意は `apps/mobile/CLAUDE.md`「確かめ方」。
画面を変えたら該当のフローを流し、無ければここに足して、この一覧にも 1 行書く。

- `home-guest` — ゲストのホーム。記録の案内（登録 CTA）から登録画面へ
- `home-username-missing` — ユーザー名未設定（`ivan@`）でログイン → ユーザー名の設定へ
  送られる → ホームにユーザー名の案内
- `setup-username-generate` — `ivan@` のユーザー名の設定で自動生成を押すと、
  `player_` + 16 進 10 桁が欄に入る。表示名の欄は無く、web のランキングで公開される旨が出る。
  登録はしない（`ivan@` を未設定のまま残す）
- `challenge-recorded` — `bob@` でログインし雀頭の符計算を 1 回走らせ、結果に記録と EXP
- `challenge-quit-recorded` — `bob@` のチャレンジで中止の確認を開いて「続ける」で戻り、答えられること、
  もう一度開いて中止するとトーストが出ること（記録付きだけで起きた、確認が出ず押せなくなる不具合の再現）
- `mypage-guest` / `mypage-username-missing` — ホームの人型のアイコンからマイページを
  開くと、記録の案内（登録 / ユーザー名の設定）と、その下に淡い見本のマイページが出る
- `mypage-signed-in` — `bob@` のマイページ。見出しと直近 7 日のアクティビティ、今日の
  棒の内訳。棒を見るなら先に `challenge-recorded` を流す（シードに EXP は無い）
- `my-record` — `bob@` のマイレコード。期間を今月に替え、全履歴で「さらに読み込む」。
  `challenge-recorded` は最後に結果からその土俵のマイレコードへ進む
- `design-surfaces` — ゲストで線と影（フラット）の見た目を撮る。ホーム・道場の帯色のボタン・
  練習の設定のタイル・チャレンジの選択肢と正誤・中止の確認ダイアログ・待ち牌の選択・
  回答中のマス。押している間の色は撮れない
- `color-roles` — `bob@` で色の役割（`apps/web/src/app/CLAUDE.md`「色の役割」）を撮る。練習一覧の
  切り替えと絞り込み・タブバー・ランキングの期間の選択中（墨）、順位のチップ（淡緑）、
  レッスンの済みマーク（正解・完了の緑）。正誤と待ち牌の選択は `design-surfaces`
- `mypage-site-links` — ゲストのホームに歯車は無く、マイページの「その他」に規約・
  プライバシーポリシー・お問い合わせ・運営者情報が並び（特商法の表記は無い）、プライバシー
  ポリシーが Safari で開く。設定を直接開くと会員限定ゲートが出る
- `preferences-signed-in` — `bob@` のマイページの「設定」の行から設定を開き、項目が使える。
  マイページには設定の行の下に「その他」が並ぶ
- `preferences-anchor` — `bob@` が `/preferences?item=ko-tsumo-input` で設定を開くと、麻雀ルールの
  節の下（練習の節）にある子のツモの入力の行まで送られ、淡緑の地で示される（レッスン等の設定へのリンクの行き先）
- `preferences-pro-rows` — 設定の Pro の 2 行（上下ランダム・理牌しない）。`bob@` はどちらも
  スイッチで理牌しないを押す、`alice@` はどちらも鍵の行で、押すとプラン画面へ。iOS だけ
- `mypage-account` — `bob@` のマイページの「アカウント」の行からアカウントを開き、ユーザー名・
  メールアドレス・ログイン方法とログアウト・退会の行が並ぶ。ログアウトするとゲストのマイページの先頭（記録の案内）へ戻る
- `exam-gate` — 昇級試験の説明の受験ゲート。ゲストは登録の案内、無級の `alice@` が 4級の
  試験を開くと先に取る級と道場への導線。模試はどちらも受けられる
- `exam-play` — `bob@`（5級）が 4級の本番を説明から始め、最初の選択肢を押し続けて終わらせる。
  結果に合否の帯が出て判定の送信が済む。合格（昇級バナー）は Maestro では作れない
- `announcements` — ゲストのホームの末尾にお知らせ 3 件（ピン留めが先）、「すべて見る」で一覧
  （末尾に広告の行）、dev seed の「書式の見本」の詳細で本文の描き方（リンク・箇条書き・引用・
  コード・表）を撮る
- `forgot-password` — ログイン画面の「パスワードを忘れた方」から再設定のリンクを送り、送った
  案内が出る。届いたメール（`bob@` 宛て）は Mailpit（`:54324`）で見る
- `navigation-history` — ゲストのマイページから登録 → ログイン → パスワードを忘れた方 →
  「ログインへ戻る」と進んでログインするとマイページへ戻る（ログイン画面が重ならない）。
  マイページの段級位から道場のタブへ移ると、下にマイページが残らない
- `lessons-rank-filter` — レッスンの目次を `?rank=kyu-5` で開くと 5級の前提レッスンだけが並び
  （「0 / 5 レッスン完了」）、下の「すべてのレッスンを見る」で全体の目次に戻る
- `practice-rank-filter` — 実戦練習を選んで残したあと、練習一覧を `?rank=<級>` で開くと基礎練習の
  その級に絞った一覧が出る（タブを開いたまま・同じ級をもう一度・起動し直して最初に、の 3 通り）。
  `bob@` では挑戦済みの練習のカードに「挑戦済み」の印が付く
- `toast-exits` — ゲストでチャレンジの中止・トレーニングの終了・和了形の点数計算の終了の
  トーストが、戻った先の画面の下に出る
- `leaderboard-signed-in` — `bob@` のマイページの「ランキングでの順位」から自分の順位の一覧を開き、
  期間を月間に替える。設定で「ランキングに表示しない」にすると一覧が非表示の案内に替わり、
  戻すと順位が戻る
- `score-tile-input` — `bob@` で和了形の点数計算を開き、点数のタイル入力（既定）を撮る。
  点数だけを答える既定では「回答する」が無く、満貫以上へ切り替えてタイルを押すとその場で
  答え合わせ。翻数と符も答える設定ではボタンが残り、満貫以上で選んだタイル（墨の枠）と、
  満貫未満へ戻したときの切り替えに添わる「満貫以上 · <点数>」。選択欄で答える設定は
  `preferences-signed-in` の設定画面で見る
- `score-tile-oya-tsumo` — `bob@` で和了形の点数計算の問題を親ツモが出るまで送り、点数のタイルが
  点数の下に小さく「オール」を積む（1 行の「4000オール」で折り返さない）ことを満貫未満・満貫以上の両方で撮る
- `bottom-sheet` — ゲストで 4 種類のシート（中身なりの説明・選ぶと閉じる選択欄（翻数。
  点数は既定でタイルなので、練習の設定で翻数と符を答える設定にして開く）・注目セルへ
  寄せる表・スクロールする一覧）を開き、取っ手ではなく本文を引き下げて閉じる。一覧は送って
  戻した後に同じ向きに引いて閉じる（スクロールとの受け渡し）。Android では戻るボタンで
  シートだけが閉じる。iOS / Android の両方で流せる（`maestro --device <エミュレーター>` で直接）
- `bottom-sheet-recorded` — `bob@` の記録付きチャレンジでシートを閉じた後に、盤面で答えられ、
  中止の確認が出て押せる
- `result-breakdown` — ゲストで和了形の点数計算の「わからない」から答え合わせを開き、
  表の下の「内訳を確認」で符 / 翻数の内訳を切り替え、閉じると入口の 1 行に戻る
- `lesson-quiz` — ゲストでレッスンの確認問題の 1-2-3 のステップ表示を撮り、1 問進めてから
  「本文を読み返す」で本文へ戻ると「確認問題に戻る（2 / 3 問目）」から同じ問題へ戻れる
- `lesson-prev-link` — ゲストで目次から 2 章目を開き、章末の「前のレッスン」で 1 章目へ移る。
  レッスン同士は置き換えなので、ヘッダーの戻る 1 回で目次へ帰る
- `mypage-plan` — `bob@` のマイページの「Pro プラン」の行からプラン画面を開き、有効なパスの状態と
  購入履歴（有効・期限切れ）が並ぶ。iOS だけ
- `mypage-notifications` — `bob@` のマイページの「通知」の行に未読の件数が出て、開くと 3 件と
  「未読 2 件」が並ぶ。「すべて既読にする」で未読が消え、戻ると件数の印も消える。既読は dev seed を
  流し直すと戻る。iOS だけ
- `practice-quota-guest` — ゲストの回数制限。和了形の点数計算を 1 問解くと最後の 1 問の案内、
  次へ進むとペイウォール。手元の web の `.env.local` に Apple の Product ID を 2 つ入れておく
- `practice-quota-pro` — `bob@`（Pro）で和了形の点数計算の「回答時間を計測する」をオンにして始め、
  盤面に回答時間が出る。残数の表示は無い
- 購入そのもの（StoreKit のシート・Sandbox の課金）は Maestro とシミュレーターでは確かめない。
  実機と Sandbox テスターでの手順は `README.md`「アプリ内課金」
- `_sign-in` — 部品。`EMAIL` / `PASSWORD` を受けてメールでログインする（パスワードの保存の確認が出たら閉じる）
- `_open-link` — 部品。`LINK` を開き、iOS 27 の「で開く?」の確認が出たら押す。フローでは `openLink` を
  直接書かずこれを使う
