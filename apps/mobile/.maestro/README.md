# Maestro フロー

操作と撮影のフロー。流し方・`testID` の引き方・Android の注意は `apps/mobile/CLAUDE.md`「確かめ方」。
画面を変えたら該当のフローを流し、無ければここに足して、この一覧にも 1 行書く。

## 端末の言語（`MAESTRO_LOCALE`）

アプリは端末の言語で辞書を選ぶ（英語の端末なら英語の画面）。`scripts/maestro.sh` は流す前に
シミュレーターの言語を `MAESTRO_LOCALE`（`ja` / `en`。既定 `ja`）に合わせる。端末の
`AppleLanguages` の先頭と `AppleLocale`（`ja` / `ja_JP`、`en-US` / `en_US`）を読み、違うときだけ
書いて端末を再起動する（値は再起動で効く）。同じ言語で続けて流すときは再起動しない。

- 下の一覧のフローは、`english-smoke` と `store-screenshots` を除いて日本語の文言で書いてあり、
  既定の `ja` で流す。英語に写さないのは日本語の画面の確認を失うため
- 英語の画面は `english-smoke` と `store-screenshots` を `MAESTRO_LOCALE=en` で流して確かめる
- シミュレーターの既定は英語なので、`maestro.sh` を通さず `maestro test` を直接流すと日本語の
  フローは最初の「次にやること」の待ちで落ちる
- `launchApp` の `arguments` で `-AppleLanguages` を渡す方式は採らない。Maestro が iOS でそれを
  アプリの起動引数として渡す確証が無く、システムの確認（リンクを開く・パスワードの保存）の
  言語も端末の設定に従うため

```sh
MAESTRO_LOCALE=en pnpm --filter @mahjong-scoring/mobile maestro english-smoke
```

## 英語のフロー

- `english-smoke` — 英語の端末でゲストのホーム（"What to do next"）・練習一覧 → 雀頭の符の説明 →
  トレーニングの盤面で 1 問・レッスン 1 章、起動し直して `bob@` でマイページ → Pro プラン（"Pro plan"・
  "Restore Purchases"）→ 設定を開き、英語の辞書の文言で確かめて `01-home` … `08-settings` を撮る。
  プラン画面と設定は日本語の文字（かな・カナ・漢字・和文の句読点と括弧）が見えないことまで確かめる
  （広告の行と牌の読み上げは辞書の外なので、他の画面では見ない。PNG を目で見る）。`MAESTRO_LOCALE=en`
- `store-screenshots` — App Store のスクリーンショットの 8 画面を撮る。下の「ストア用の撮影」

## ストア用の撮影（`store-screenshots`）

App Store Connect が必須とする 6.9 インチの `iPhone 17 Pro Max` に Release ビルドを入れて流す。
PNG は Git に入れない（フローから撮り直せ、版を上げるたびに差し替えるバイナリになる）。
`MAESTRO_OUTPUT_DIR` で手元の置き場所に出し、App Store Connect へ上げるときはそこから取る。

```sh
pnpm --filter @mahjong-scoring/mobile sim:release "iPhone 17 Pro Max"
# 時計・電波・電池の表示を固定する（任意。端末を再起動すると外れるので、言語を替えた後に掛ける）
xcrun simctl status_bar booted override --time 9:41 --batteryState charged \
  --batteryLevel 100 --cellularBars 4 --wifiBars 3
SIMULATOR_NAME="iPhone 17 Pro Max" MAESTRO_LOCALE=en MAESTRO_OUTPUT_DIR=<置き場所> \
  pnpm --filter @mahjong-scoring/mobile maestro store-screenshots
```

時計を固定するなら、先に同じ言語で一度 `maestro.sh` を流して言語を合わせておく（言語を替えると
端末を再起動し、固定が外れる）。

撮る画面と順（ストアの検索結果に出るのは先頭の 3 枚なので、アプリで何ができるかを先に置く）:

1. `01-home` — ホームの「次にやること」。学ぶ → 練習する → 認定される の道筋の入口で、
   アプリの使い方が 1 枚で分かる
2. `02-practice-list` — 練習一覧（基礎練習）。練習の数と幅を見せる
3. `03-challenge-board` — チャレンジの盤面（雀頭の符）。牌を見て答える中心の操作
4. `04-answer-check` — 1 つ答えた後の正誤の表示。その場で答え合わせできること
5. `05-lesson` — レッスンの本文の先頭。練習の前に読める教本があること
6. `06-score-table` — 点数表。引ける早見表があること
7. `07-dojo` — 道場（段級位の道筋）。目標があること
8. `08-plan` — Pro プラン。課金は最後に置く（何ができるアプリかを先に見せる）

1〜7 はゲスト（入れたばかりの人が見る画面。ユーザー名や記録が写らない）、8 だけ無料の `alice@`
（購入履歴が無く、プランを選ぶ欄が出る）。Pro の `bob@` は web で買った履歴の行（購入元「Web」）が
写るので使わない（アプリの中で他の購入の経路を見せない。審査ガイドライン 3.1.1）。プランを選ぶ欄は
販売中（手元の web の `.env.local` に Apple の Product ID が 2 つある）ときだけ出て、価格は
StoreKit の値（取れなければ購入画面で確かめる旨の案内 `mobilePlan.offers.priceUnavailable`）になる。
練習一覧の 3 枚目には広告のカード（手元の web の広告配信の中身）が出るので、撮った PNG で中身を確かめる。

文言を待つところは「英語|日本語」の正規表現にしてあり、`MAESTRO_LOCALE=ja` でも同じ 8 画面を撮れる。

## 戻り方（`_back` / `screen-close` / `sheet-close`）

ヘッダー左に何が出るかは画面の置き場所で決まる（`src/components/screen.tsx` の `Screen` の TSDoc の表）。
フローでは出ているものに合わせて次のどれかで戻る。どれも押した先の画面の要素で待つ。

| ヘッダー左                                                      | 戻り方                                                                             |
| --------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| OS 標準の戻る（`<`。同じスタックに下の画面がある）              | `runFlow: { file: _back.yaml }`。戻った先の testID を `BACK_TO` に渡すと保険が付く |
| ×（解答中・結果・マイページ以下のモーダルの組の先頭）           | `tapOn: { id: "screen-close" }`                                                    |
| ×（用語・お知らせ・級の詳細のシートの見出しの右）               | `tapOn: { id: "sheet-close" }`                                                     |
| `<`（ディープリンクで直接開き、下に画面が無い。入口へ置き換え） | `tapOn: { id: "screen-back" }`                                                     |

- OS 標準の戻るには testID が無い（ネイティブスタックのヘッダーが描くボタンで、アプリから印を
  付けられない）。読み上げの名前は端末の言語と下の画面の見出しで変わる（「戻る」のことも
  「用語集」のこともある）ので、`_back` は画面の左端から右へ引く（言語に依らない）。`BACK_TO` を
  渡すと、引いた後にその要素が見えなければ、UIKit が戻るボタンに付ける識別子 `BackButton` で押す
- チャレンジの × は中止の確認を挟む（「チャレンジを中止しますか？」→「中止する」）。
  トレーニング・和了形 / 聴牌形の点数計算の × はそのまま閉じ、戻った先に終了のトーストが出る
- × は「モーダルを閉じる」で、下にあった画面へ戻る（説明画面から始めたなら説明画面、
  ディープリンクで開いたならそのとき下にあった画面）
- タブの入口のヘッダー左には何も出ない。タブは `tab-<名前>`（`tab-home` 等）で押す

## 日本語のフロー

- `nav-skeleton` — ゲストで画面の骨格（OS のタブバー・OS のヘッダー）を撮る。5 つのタブを順に開き、
  ホームを下へスクロールしたところ（見出しはヘッダーの左端に残り、iOS 26 以降はタブバーが縮む）、道場の「?」、
  練習の説明から OS の戻る（`_back`）で一覧へ、トレーニングの × で説明画面にトースト、見つからない
  レッスンの「目次へ」でレッスンのタブへ
- `session-modal` — ゲストで解答中のモーダル。説明からチャレンジが下から出て（タブバーは隠れる）、
  × で中止の確認、中止すると説明へ戻ってトースト。翻数のトレーニングでドラの説明（シート）から
  設定を開くと盤面の上に重なり（会員限定ゲート）、× で盤面へ戻って解答を続けられる
- `glossary-search` — ゲストで用語集の絞り込み。検索欄にローマ字で打って当てはまる語だけが残る、
  当てはまらない語の表示、分類のチップ（牌の種類）での絞り込み
- `sheets` — ゲストで用語集から用語（暗刻）のシートを半分の高さで撮り、引き上げて全画面の段へ。
  「関連する用語」の明刻でシートを積まずに中身が替わる。「この用語が出てくる章」の行でシートが閉じてレッスンが開く。
  お知らせの詳細（「書式の見本」。手元の web が要る）と級の詳細（5級）も開いて撮り、× で閉じる
- `account-modal` — ゲストでホームのアバターからマイページが下から出る（× 付き・タブバーは隠れる）。
  記録の案内から登録へ進むとモーダルの中に積まれ、OS の戻るでマイページへ、× でホームへ戻る
- `home-guest` — ゲストのホーム。記録の案内（登録 CTA）から登録画面へ
- `home-username-missing` — ユーザー名未設定（`ivan@`）でログイン → ユーザー名の設定へ
  送られる → ホームにユーザー名の案内
- `setup-username-generate` — `ivan@` のユーザー名の設定で自動生成を押すと、
  `player_` + 16 進 10 桁が欄に入る。表示名の欄は無く、web のランキングで公開される旨が出る。
  登録はしない（`ivan@` を未設定のまま残す）
- `challenge-recorded` — `bob@` でログインし雀頭の符計算を 1 回走らせ、結果に記録と EXP
- `challenge-quit-recorded` — `bob@` のチャレンジで中止の確認を開いて「続ける」で戻り、答えられること、
  もう一度開いて中止するとトーストが出ること（記録付きだけで起きた、確認が出ず押せなくなる不具合の再現）
- `mypage-guest` / `mypage-username-missing` — ホームの人型のアイコンからマイページを
  開くと、記録の案内（登録 / ユーザー名の設定）と、その下に淡い見本のマイページが出る
- `mypage-signed-in` — `bob@` のマイページ。見出しと直近 7 日のアクティビティ、今日の
  棒の内訳。棒を見るなら先に `challenge-recorded` を流す（シードに EXP は無い）
- `pull-to-refresh` — `bob@` のマイページで本文を下へ引き、読み直したあとも中身が出ている。
  手元の web は速く更新の印はすぐ消えるので、読み直したことは web のログ（`/api/mobile/v1/mypage` が
  引くたびに 1 回増える）で確かめる
- `my-record` — `bob@` のマイレコード。期間を今月に替え、全履歴で「さらに読み込む」。
  `challenge-recorded` は最後に結果からその土俵のマイレコードへ進む
- `design-surfaces` — ゲストで線と影（フラット）の見た目を撮る。ホーム・道場の帯色のボタン・
  練習の設定のタイル・チャレンジの選択肢と正誤・中止の確認ダイアログ・待ち牌の選択・
  回答中のマス。押している間の色は撮れない
- `color-roles` — `bob@` で色の役割（`apps/web/src/app/CLAUDE.md`「色の役割」）を撮る。練習一覧の
  切り替えと絞り込み・タブバー・ランキングの期間の選択中（墨）、順位のチップ（淡緑）、
  レッスンの済みマーク（正解・完了の緑）。正誤と待ち牌の選択は `design-surfaces`
- `mypage-site-links` — ゲストのホームに歯車は無く、マイページの「その他」に規約・
  プライバシーポリシー・お問い合わせ・運営者情報が並び（特商法の表記は無い）、プライバシー
  ポリシーが Safari で開く。設定を直接開くと会員限定ゲートが出る
- `preferences-signed-in` — `bob@` のマイページの「設定」の行から設定を開き、項目が使える。
  マイページには設定の行の下に「その他」が並ぶ
- `preferences-anchor` — `bob@` が `/preferences?item=ko-tsumo-input` で設定を開くと、麻雀ルールの
  節の下（練習の節）にある子のツモの入力の行まで送られ、淡緑の地で示される（レッスン等の設定へのリンクの行き先）
- `preferences-pro-rows` — 設定の Pro の 2 行（上下ランダム・理牌しない）。`bob@` はどちらも
  スイッチで理牌しないを押す、`alice@` はどちらも鍵の行で、押すとプラン画面へ。iOS だけ
- `mypage-account` — `bob@` のマイページの「アカウント」の行からアカウントを開き、ユーザー名・
  メールアドレス・ログイン方法とログアウト・退会の行が並ぶ。ログアウトするとゲストのマイページの先頭（記録の案内）へ戻る
- `exam-gate` — 昇級試験の説明の受験ゲート。ゲストは登録の案内、無級の `alice@` が 4級の
  試験を開くと先に取る級と道場への導線。模試はどちらも受けられる
- `exam-play` — `bob@`（5級）が 4級の本番を説明から始め、最初の選択肢を押し続けて終わらせる。
  結果に合否の帯が出て判定の送信が済む。合格（昇級バナー）は Maestro では作れない
- `announcements` — ゲストのホームの末尾にお知らせ 3 件（ピン留めが先）、「すべて見る」で一覧
  （末尾に広告の行）、dev seed の「書式の見本」の詳細で本文の描き方（リンク・箇条書き・引用・
  コード・表）を撮る
- `forgot-password` — ログイン画面の「パスワードを忘れた方」から再設定のリンクを送り、送った
  案内が出る。届いたメール（`bob@` 宛て）は Mailpit（`:54324`）で見る
- `navigation-history` — ゲストのマイページから登録 → ログイン → パスワードを忘れた方 →
  「ログインへ戻る」と進んでログインするとマイページへ戻る（ログイン画面が重ならない）。
  マイページの段級位から道場のタブへ移ると、下にマイページが残らない
- `lessons-rank-filter` — レッスンの目次を `?rank=kyu-5` で開くと 5級の前提レッスンだけが並び
  （「0 / 5 レッスン完了」）、下の「すべてのレッスンを見る」で全体の目次に戻る
- `practice-rank-filter` — 実戦練習を選んで残したあと、練習一覧を `?rank=<級>` で開くと基礎練習の
  その級に絞った一覧が出る（タブを開いたまま・同じ級をもう一度・起動し直して最初に、の 3 通り）。
  `bob@` では挑戦済みの練習のカードに「挑戦済み」の印が付く
- `endless-scroll-top` — ゲストで和了形の点数計算の盤面を回答欄まで下へ送り、「わからない」で
  答え合わせへ、「次の問題へ」で次の問題へ進む。どちらの切り替えでも本文が先頭へ戻り、手牌の帯が
  ヘッダー（× と見出し）の裏に潜らずに見える（撮った画面で見る）
- `toast-exits` — ゲストでチャレンジの中止・トレーニングの終了・和了形の点数計算の終了の
  トーストが、戻った先の画面の下に出る
- `leaderboard-signed-in` — `bob@` のマイページの「ランキングでの順位」から自分の順位の一覧を開き、
  期間を月間に替える。設定で「ランキングに表示しない」にすると一覧が非表示の案内に替わり、
  戻すと順位が戻る
- `score-tile-input` — `bob@` で和了形の点数計算を開き、点数のタイル入力（既定）を撮る。
  点数だけを答える既定では「回答する」が無く、満貫以上へ切り替えてタイルを押すとその場で
  答え合わせ。翻数と符も答える設定ではボタンが残り、満貫以上で選んだタイル（墨の枠）と、
  満貫未満へ戻したときの切り替えに添わる「満貫以上 · <点数>」。選択欄で答える設定は
  `preferences-signed-in` の設定画面で見る
- `score-tile-oya-tsumo` — `bob@` で和了形の点数計算の問題を親ツモが出るまで送り、点数のタイルが
  点数の下に小さく「オール」を積む（1 行の「4000オール」で折り返さない）ことを満貫未満・満貫以上の両方で撮る
- `bottom-sheet` — ゲストで 4 種類のシート（中身なりの説明・選ぶと閉じる選択欄（翻数。
  点数は既定でタイルなので、練習の設定で翻数と符を答える設定にして開く）・注目セルへ
  寄せる表・スクロールする一覧）を開き、取っ手ではなく本文を引き下げて閉じる。一覧は送って
  戻した後に同じ向きに引いて閉じる（スクロールとの受け渡し）。Android では戻るボタンで
  シートだけが閉じる。iOS / Android の両方で流せる（`maestro --device <エミュレーター>` で直接）
- `bottom-sheet-recorded` — `bob@` の記録付きチャレンジでシートを閉じた後に、盤面で答えられ、
  中止の確認が出て押せる
- `result-breakdown` — ゲストで和了形の点数計算の「わからない」から答え合わせを開き、
  表の下の「内訳を確認」で符 / 翻数の内訳を切り替え、閉じると入口の 1 行に戻る
- `lesson-quiz` — ゲストでレッスンの確認問題の 1-2-3 のステップ表示を撮り、1 問進めてから
  「本文を読み返す」で本文へ戻ると「確認問題に戻る（2 / 3 問目）」から同じ問題へ戻れる
- `lesson-prev-link` — ゲストで目次から 2 章目を開き、章末の「前のレッスン」で 1 章目へ移る。
  レッスン同士は置き換えなので、OS の戻る（`_back`）1 回で目次へ帰る
- `mypage-plan` — `bob@` のマイページの「Pro プラン」の行からプラン画面を開き、有効なパスの状態と
  購入履歴（有効・期限切れ）が並ぶ。iOS だけ
- `mypage-notifications` — `bob@` のマイページの「通知」の行に未読の件数が出て、開くと 3 件と
  「未読 2 件」が並ぶ。「すべて既読にする」で未読が消え、戻ると件数の印も消える。既読は dev seed を
  流し直すと戻る。iOS だけ
- `practice-quota-guest` — ゲストの回数制限。和了形の点数計算を 1 問解くと最後の 1 問の案内、
  次へ進むとペイウォール。手元の web の `.env.local` に Apple の Product ID を 2 つ入れておく
- `practice-quota-pro` — `bob@`（Pro）で和了形の点数計算の「回答時間を計測する」をオンにして始め、
  盤面に回答時間が出る。残数の表示は無い
- 購入そのもの（StoreKit のシート・Sandbox の課金）は Maestro とシミュレーターでは確かめない。
  実機と Sandbox テスターでの手順は `README.md`「アプリ内課金」
- `_back` — 部品。OS の戻るで 1 画面戻る（画面の左端から右へ引く。`BACK_TO` を渡すと、その要素が
  見えなければ戻るボタン（`BackButton`）を押す）。上の「戻り方」
- `_sign-in` — 部品。`EMAIL` / `PASSWORD` を受けてメールでログインする（パスワードの保存の確認が出たら閉じる）
